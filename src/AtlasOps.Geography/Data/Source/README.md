# Geography source data

The `countries` and `subdivisions` directories are vendored from
[`countries/countries-data-json`](https://github.com/countries/countries-data-json)
at the commit recorded in `SOURCE_COMMIT`.

The upstream dataset is distributed under the MIT license copied into this
directory. AtlasOps preserves the source records as immutable reference data
and stores user edits separately as local overrides.
